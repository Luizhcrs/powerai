# Security Policy

## Supported Versions

Security updates are actively applied to the latest stable release of PowerAI.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security and privacy of PowerAI seriously. PowerAI is designed from the ground up as a **Local-First, zero-telemetry** tool.

If you discover a security vulnerability or potential code-execution flaw:

1. **Do NOT open a public GitHub issue.**
2. Please report the vulnerability privately by emailing [luizgc_@hotmail.com](mailto:luizgc_@hotmail.com) with:
   - A description of the vulnerability and its potential impact.
   - Step-by-step reproduction steps or proof-of-concept script.
   - Your environment (OS, Shell, Ollama version).

### What to Expect:
- An acknowledgment of your report within 48 hours.
- A timely investigation and patch release.
- Public recognition in the release notes once the vulnerability has been resolved (unless you prefer to remain anonymous).
